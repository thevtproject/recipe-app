# Security Policy

## Supported Versions

This private family recipe app is maintained from the `dev` and `master` branches. Security fixes are applied to the current deployed version.

## Reporting a Vulnerability

Please report suspected vulnerabilities privately to the project maintainer via GitHub private vulnerability reporting or direct email to the repository owner.

Do not open a public issue for security-sensitive findings.

## Response Expectations

- Acknowledgment target: within 48 hours
- Initial triage target: within 7 days
- Critical fix target: as soon as practical, depending on severity and exploitability

## Disclosure

Because this is a private family application, vulnerability details should remain private until a fix is deployed and the maintainer approves disclosure.
