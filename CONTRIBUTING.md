# Contributing

Thanks for helping improve the family recipe app.

## Workflow

1. Create a branch from `dev`.
2. Keep changes small and focused.
3. Follow `AGENTS.md` conventions.
4. Run checks before opening a PR:
   ```bash
   npx tsc --noEmit
   npm run build
   ```
5. Open a PR into `dev` with a short summary and testing notes.

## Bug reports

Include what happened, what you expected, steps to reproduce, and screenshots or logs if useful.

## Commit style

Use simple prefixes when possible: `feat:`, `fix:`, `chore:`, or `docs:`.

## Security

Do not report vulnerabilities publicly. See `SECURITY.md`.
